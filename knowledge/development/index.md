# Development

ソフトウェア開発の慣習と判断基準。

- [Artifact](./artifact/index.md) — 評価対象のRequirements・Behavior・Implementationを定義する
- [Verification](./verification/index.md) — 与えられた要求・仕様への適合を、論証と証拠によって評価する
- [Validation](./validation/index.md) — 要求・仕様と実現された振る舞いが、利用者の目的・利用状況に適するかを評価する
- [Repository](./repository/index.md) — リポジトリの状態と、そこから知識を取得する経路を評価する
- [Issue](./issue/index.md) — リポジトリに記録されるIssueを定義する
- [Pull Request](./pr-request/index.md) — Pull Request の形式モデルとガイドライン
