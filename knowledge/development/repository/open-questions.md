# Repositoryの未定義事項

[モデル](./model.md)は、リポジトリ状態と知識へのアクセスを整理する枠組みであり、各条件の判定手続きはまだ与えていない。

| 項目                   | 未定義の内容                                                       |
| ---------------------- | ------------------------------------------------------------------ |
| 必要な知識             | 将来必要となる知識の集合を、想定する利用者とタスクからどう定めるか |
| アクセス経路の成立     | 所定の経路で取得できると判断する条件と、マージ後の参照可能性       |
| 情報の有効条件         | 状態・遷移・外部環境に依存する情報を厳密に区別する条件             |
| Repository Loadの比較  | 異なる状態の負荷を、利用者とタスクを固定したうえでどう比較するか   |
| Repository Rulesの表現 | 受け入れに必要な規則を、検証責務の導出に使える形でどう記述するか   |

情報が有効であることと、情報を取得できることは別の条件である。また、知識へのアクセス経路と、論証における論理的な支持関係も区別する。

変更による状態の遷移と、その分割・提示・配置に固有の課題は[PRの未定義事項](../pr-request/open-questions.md)で扱う。
