# Repository

リポジトリの状態と、その状態から知識を取得する経路を扱う知識体系。変更の単位であるPRに依存せず、ある時点のリポジトリを評価する。

- [モデル](./model.md) — リポジトリ状態、知識へのアクセス層、知識の保持、情報の有効条件、Repository Rules、Repository Loadを定義する
- [未定義事項](./open-questions.md) — 必要な知識、アクセス経路、有効条件、負荷の比較について、次に形式化する課題

参照する知識体系：[Artifact](../artifact/index.md)。状態を変える変更は[PR](../pr-request/index.md)で扱う。
