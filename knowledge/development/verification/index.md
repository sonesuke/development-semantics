# Verification

Requirementsを起点に、要求が目的に適していると仮定し、実装がその要求を満たすかを論証と証拠によって問う知識体系。PRに限らず、設計や既存実装の評価にも適用する。

- [モデル](./model.md) — 論証、検証責務、網羅性、証拠の十分性を定義する
- [未定義事項](./open-questions.md) — 適合関係と証拠の受け入れ条件について、次に形式化する課題

評価対象のRequirements・Behavior・Implementationは[Artifact](../artifact/index.md)で定義する。要求・仕様そのものが利用者の目的に適するかは[Validation](../validation/index.md)で扱う。[PR](../pr-request/index.md)では、このモデルを変更の検証と受け入れ判断に適用する。
