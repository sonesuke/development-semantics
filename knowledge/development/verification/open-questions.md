# Verificationの未定義事項

[モデル](./model.md)は検証の構成要素を整理する枠組みであり、一般的な判定手続きはまだ与えていない。

| 項目           | 未定義の内容                                                             |
| -------------- | ------------------------------------------------------------------------ |
| 適合と性質保存 | 対象間の対応で保存すべき性質と、その保存関係をどう定義するか             |
| VOの網羅性     | 要求・仕様・対象・規則から必要な責務を十分に導出したと判断する条件       |
| 論証の妥当性   | 推論の妥当性と、外部の前提・補題を利用できる条件                         |
| 証拠の十分性   | 設計説明・テスト・証明による支持を、適用範囲と前提のもとで受け入れる条件 |

PRの分割や受け入れへの適用は[PRの未定義事項](../pr-request/open-questions.md)で扱う。要求・仕様が目的に適するかの評価条件は[Validationの未定義事項](../validation/open-questions.md)で扱う。
