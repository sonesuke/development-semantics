# Validation

Requirementsを起点に、実装が要求どおりであると仮定し、その要求が利用者の目的・利用状況に適するかを問う知識体系。PRに限らず、要求の策定、設計、実装後の評価にも適用する。

- [モデル](./model.md) — 目的・利用状況・結果集合から適合条件を定義し、証拠による判断とVerificationへの接続を示す
- [未定義事項](./open-questions.md) — 目的の妥当性と、評価範囲・証拠の十分性について残る課題

評価対象のRequirements・Behaviorは[Artifact](../artifact/index.md)で定義する。与えられた要求・仕様への適合は[Verification](../verification/index.md)で扱う。[PR](../pr-request/index.md)では、採用した要求の根拠を参照し、要求や利用上の前提が変わる場合に評価を見直す。
