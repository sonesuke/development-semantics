# Validationの未定義事項

[モデル](./model.md)では、結果集合の包含関係によって要求と振る舞いの適合条件を定義した。一方、目的の捉え方や、有限の証拠からその条件を受け入れる手続きは別の問題であり、次の条件はまだ定めていない。

| 項目           | 未定義の内容                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 目的と評価基準 | 問題の捉え方と評価基準が、利用者の必要を十分に反映していると判断する条件                         |
| 評価範囲       | 利用者・タスク・環境のどの範囲を扱えば十分か、評価した状況からどこまで一般化できるか             |
| 証拠の十分性   | 判断関係 \(E\vdash_{K,F}\varphi\) の推論規則と健全性、観察・試作・試験・運用結果を受け入れる条件 |
| 目的の競合     | 関係者間の目的や制約が競合するときの、優先順位と採用判断の条件                                   |
| 再評価         | 目的・利用状況・要求・実装の変化に対し、どの範囲の評価をやり直す必要があるか                     |

また、現モデルはすべての対象状況で許容結果だけが生じることを要求する。成功率・期待効用・リスクの閾値で評価するモデルへの拡張と、要求を実現する実装の存在条件も未定義である。

[Verification](../verification/index.md)との接続では、要求の変更に伴う検証責務の見直しと、共通の証拠がそれぞれ支持する命題を明確にする必要がある。
