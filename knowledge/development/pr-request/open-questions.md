# PR形式モデルの未定義事項

本モデルは、要求から実装への対応、論証の構造、知識へのアクセスを整理する枠組みである。以下は、概念の方向性が示されていても、厳密な判定条件がまだ定まっていない事項である。

| 優先 | 項目                 | 未定義の内容                                                 |
| ---- | -------------------- | ------------------------------------------------------------ |
| 1    | 性質保存             | 各マッピングで保存すべき性質と、その保存関係をどう定義するか |
| 2    | 部分構造の閉包性     | 一つのPRで論証が完結する条件、外部の前提を利用できる条件     |
| 3    | Behaviorの独立性     | 別々の変更を安全に合成できる条件                             |
| 4    | 論証の等価性         | 異なる分割・提示が同じ論証を表す条件                         |
| 5    | 構造的冗長性         | 不必要な重複、参照、往復を判定する条件                       |
| 6    | 情報の有効条件       | 状態・遷移・外部環境に依存する情報を厳密に区別する条件       |
| 7    | Verificationの十分性 | 設計・テスト・証明による支持を受け入れる条件                 |
| 8    | 構造比較の限界       | 複数の非支配な構造をどう扱うか                               |

1〜6は主として論理構造の問題である。7は証拠の信頼性とRepository Rulesに関わり、8は一意の最適解が存在しない可能性を含む。

知識の保持を評価するには、将来必要となる知識の集合、想定する利用者とタスク、所定のアクセス経路、マージ後の参照可能性を具体化する必要もある。これは有効条件と構造的冗長性の議論に関係するが、情報が有効であることと、情報を取得できることは別の条件である。

## 次の形式化

まず[性質保存](./model.md#変更の意味論)と[部分構造の閉包性](./strategies.md#pr分割と階層化)を定義する。この二つが定まれば、PRの分割と論証の完結性を同じ形式体系の中で扱えるようになる。

その際、依存関係をすべてPR内へ複製することを閉包性とみなさず、外部の前提・補題・証拠を利用する条件も検討する。また、[知識へのアクセス経路](./model.md#知識の保持)と論理的な支持関係を区別する必要がある。
