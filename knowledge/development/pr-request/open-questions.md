# PR形式モデルの未定義事項

本モデルは、要求から実装への対応、論証の構造、知識へのアクセスを整理する枠組みである。以下は、概念の方向性が示されていても、厳密な判定条件がまだ定まっていない事項である。

| 優先 | 項目             | 未定義の内容                                                                         |
| ---- | ---------------- | ------------------------------------------------------------------------------------ |
| 1    | 性質保存の適用   | Verificationで扱う保存関係を、PRの各マッピングと変更前後へどう適用するか             |
| 2    | 部分構造の閉包性 | 一つのPRで論証が完結する条件、外部の前提を利用できる条件                             |
| 3    | Behaviorの独立性 | 別々の変更を安全に合成できる条件                                                     |
| 4    | 論証の等価性     | 異なる分割・提示が同じ論証を表す条件                                                 |
| 5    | 構造的冗長性     | 不必要な重複、参照、往復を判定する条件                                               |
| 6    | PRの受け入れ基準 | Verificationの証拠の十分性とRepository Rulesを、延期・免除を含む判断にどう適用するか |
| 7    | 構造比較の限界   | 複数の非支配な構造をどう扱うか                                                       |

1〜5は主として論理構造の問題である。6はRepository Rulesに基づく受け入れ判断に関わり、7は一意の最適解が存在しない可能性を含む。

性質保存、VOの網羅性、論証と証拠の十分性の一般的な条件は[Verificationの未定義事項](../verification/open-questions.md)で扱う。要求や実現された振る舞いが目的に適するかの評価条件は[Validationの未定義事項](../validation/open-questions.md)で扱う。ここでは、それらのPRへの適用と、変更の分割・提示・配置に固有の課題を扱う。

知識の保持、情報の有効条件、Repository Loadの比較など、リポジトリ状態についての課題は[Repositoryの未定義事項](../repository/open-questions.md)で扱う。

## 次の形式化

まず[Verificationの性質保存](../verification/model.md#性質保存)をPRの変更前後へ適用する条件と、[部分構造の閉包性](./strategies.md#pr分割と階層化)を定義する。この二つが定まれば、PRの分割と論証の完結性を同じ形式体系の中で扱えるようになる。

その際、依存関係をすべてPR内へ複製することを閉包性とみなさず、外部の前提・補題・証拠を利用する条件も検討する。また、[知識へのアクセス経路](../repository/model.md#知識へのアクセス層)と論理的な支持関係を区別する必要がある。
