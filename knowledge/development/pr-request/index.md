# Pull Request

Pull Request（PR）の形式モデルと、そこから導く性質、構成を選ぶための戦略。

よいPRとは、要求から実装までの構造的な対応関係について、その正当性を必要十分な証拠で示し、人間が自然に理解できるように構成され、将来必要な知識へのアクセスも維持された変更である。

- [モデル](./model.md) — 変更・論証・物理的構造・知識の保持・認知負荷と、品質の受け入れ条件を定義する
- [定理](./theorems.md) — モデルの定義と仮定から導ける性質と、その証明
- [構成戦略](./strategies.md) — PR・Commitの分割、提示順序、情報と証拠の配置を選ぶ
- [未定義事項](./open-questions.md) — 判定条件が定まっていない概念と、次に形式化する課題

定義を置くこと、そこから性質を導くこと、具体的な構成を選ぶことを分ける。モデルは形式化の途中にあり、戦略の採用だけで品質や負荷の改善を保証しない。
